## 2. Environment facts that cost time to learn

- **The Odoo test command.** `docker compose exec odoo` is the **Odoo 18** container and mounts
  `odoo/addons18` — the wrong addon entirely. The v19 addon is behind the `odoo19-trial` profile:
  ```bash
  docker compose --profile odoo19-trial run --rm --no-deps -T odoo19-trial \
    odoo --no-http --test-enable --stop-after-init \
    --workers=0 --max-cron-threads=0 \
    -d masterfischer_o19_foundation_test -u picking_assistant_integration
  ```
  Every flag is load-bearing. `--max-cron-threads=0` and `run --rm` exist because the test database
  sits on the shared Postgres: a concurrently running Odoo service with cron threads writes
  `ir_cron` during module load and kills the run with `SerializationFailure` before a single test
  executes. **Never leave a long-running `odoo19-trial` container up.**
- **`masterfischer` is the LIVE database.** Tests use `masterfischer_o19_foundation_test`.
- **pytest is vendored gitignored at `backend/.deps` in the MAIN tree and does not exist in
  worktrees.** From a worktree, point `PYTHONPATH` at the main tree's copy. Do not build a venv.
  Infrastructure tests additionally need `infrastructure/scripts` on the path.
- **This is WSL2 over `/mnt/c` and it is slow.** A subagent that runs a long command without
  printing gets killed by a stall watchdog at 600 seconds. Tell agents to print between steps and
  to write their report incrementally — three agents lost work to this.
- **`backend/app/main.py` is entirely CRLF.** `git diff --check` warns on every added line; that is
  expected noise.

## 4. What this session actually established

Seven remediation tasks completed across three lanes, each through implement → adversarial review →
fix round → scoped re-review. Every single task needed at least one fix round. The reviews found
things the implementers' green suites did not, and several findings were defects in **the plans**,
not the code.

Patterns worth carrying into tomorrow's work:

- **Make the guard fail before believing it.** Three separate guards in this session passed while
  proving nothing: a CSRF/dependency guard that covered 4 of 5 routes while asserting `4 == 4`; a
  fixture test that asserted "exactly one mutation" but only checked top-level keys; an allowlist
  derivation test that accepted any type appearing anywhere in the reference graph. Each was caught
  only by deliberately breaking the thing it guarded and confirming a red.
- **A race test that cannot distinguish "no deadlock" from "no race" is not a race test.** Demanding
  a positive control on R2's race tests cost one fix round and immediately surfaced a real
  pre-existing bug — a raw `psycopg2.UniqueViolation` leaking to callers because Odoo runs
  REPEATABLE READ and the collision handler re-SELECTed under a stale snapshot. Structurally
  invisible to any single-cursor test.
- **Audit every site, not the ones you changed.** R2's full lock-site audit found a *second*
  inverted path nobody had looked at.
- **Derive from the specification, not from the instruction.** The PDF whitespace class was written
  from Python's `\s` instead of ISO 32000-1 Table 1 (NUL missing → bypass). The fix I wrote then
  handed over a literal delimiter class, and the same root cause repeated (`{`/`}` → bypass). Both
  tables are now named constants substituted into the pattern so they cannot drift.
- **A test that passes against the vulnerable implementation is worth deleting.** R3's implementer
  threw away its own TOCTOU test on discovering it passed against a deliberately reverted, broken
  version, and said so.
