# Odoo 18 Addons

This directory contains the Odoo 18-compatible custom addons used by the live/default `odoo` service and `odoo-lager-2`.

`odoo/addons` contains the Odoo 19 port used by the `odoo19-trial` service. Keep the directories separate: Odoo 19 security XML uses `res.groups.privilege`, while Odoo 18 uses `res.groups.category_id`.
